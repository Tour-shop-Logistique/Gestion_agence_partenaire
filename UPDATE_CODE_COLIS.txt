💻 UTILISATION
═══════════════════════════════════════════════════════════════

JavaScript:
  generateColisCode({ 
    codeAgence: 'AGC001', 
    numeroColis: 1,
    typeExpedition: 'MARITIME' 
  });
  // → "DHD-MR-001-AGC001"

React Hook:
  const { genererCodeColis } = useCodeGenerator();
  const code = genererCodeColis({ 
    numeroColis: 5, 
    typeExpedition: 'AFRIQUE' 
  });
  // → "AF-005-AGC001"

⚠️ ACTION REQUISE - BACKEND
═══════════════════════════════════════════════════════════════

Le BACKEND doit être modifié pour:

1. Accepter le paramètre "type_expedition" lors de la création
2. Générer les codes avec le nouveau format:
   
   switch ($type_expedition) {
       case 'AERIEN':   $prefix = 'DHD-AR'; break;
       case 'MARITIME': $prefix = 'DHD-MR'; break;
       case 'AFRIQUE':  $prefix = 'AF'; break;
       case 'CA':       $prefix = 'CA'; break;
       case 'LD':       $prefix = 'LD'; break;
       default:         $prefix = 'DHD-AR';
   }
   
   $code = "{$prefix}-{$numero}-{$code_agence}";

3. Maintenir une séquence par type d'expédition
